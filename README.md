# 💼 HR Attrition Prediction

This project focuses on analyzing HR data to identify key factors influencing employee attrition and predicting whether an employee will stay or leave the organization using machine learning techniques.

---

## 📊 Project Overview

Employee attrition is a major challenge for organizations aiming to retain top talent.  
Through Exploratory Data Analysis (EDA) and predictive modeling, this project uncovers important insights into employee behavior, satisfaction, and workplace factors influencing attrition.

---

## ⚙️ Tools & Technologies

- **Programming Language:** Python  
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Plotly  
- **Visualization:** Tableau (Dashboard)  
- **Model Used:** Logistic Regression  
- **IDE:** Jupyter Notebook  

---

## 🧩 Key Steps

1. **Data Preprocessing** – Cleaning, encoding categorical features, and handling missing values.  
2. **Exploratory Data Analysis (EDA)** – Understanding patterns between attributes like Work-Life Balance, Salary, and Job Satisfaction with Attrition.  
3. **Model Building** – Applied Logistic Regression to classify employees as “Stay” or “Leave.”  
4. **Model Evaluation** – Achieved around **88% accuracy** with improved feature selection.   

---

## 📈 Results & Insights

- Employees with low job satisfaction or poor work-life balance show higher attrition rates.  
- Early-career employees are more likely to switch jobs.  
- Higher salaries and stock options reduce the probability of attrition.  
- Departments with target-based roles (like Sales) exhibit higher turnover rates.
